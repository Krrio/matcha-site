# Matchacho — interactive one-page rebuild

Interaktywna rekonstrukcja referencji jako normalna strona w **Next.js 15 + TypeScript + GSAP**.

To nie jest screenshot udający stronę. Nagłówek, hero, filtry, sekcja experience, karty produktów, koszyk, CTA i footer są zbudowane z normalnego HTML/React + CSS. Obrazy z referencji są używane wyłącznie jako assety fotograficzne/produktowe.

## Uruchomienie

```bash
npm install
npm run dev
```

Otwórz `http://localhost:3000`.

## Interakcje

- sticky navigation i smooth scroll,
- wybór rytuału w hero,
- interaktywne benefity w sekcji Experience,
- dodawanie produktów do koszyka,
- wysuwany koszyk z licznikiem i sumą,
- responsywne menu mobilne,
- animacje wejścia i scroll reveal w GSAP + ScrollTrigger,
- prefers-reduced-motion support.
